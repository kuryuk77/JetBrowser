# JetBrowser

Android TV ve telefon için tarayıcı + telefondan touchpad/klavye kumandası.

- **JetBrowser**: TV'de ve telefonda tarayıcı (sekmeler, yer imleri, geçmiş, indirme, gizli sekme, reklam/pop-up engeli, TV kumandası imleci).
- **Jet Kumanda**: Telefonda ikinci simge. Aynı Wi-Fi'daki TV'yi bulur; touchpad + klavye olur.

APK her `main` push'unda GitHub Actions ile derlenir → Releases.
